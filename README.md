# oceano-webchat

Página de homologação das assistentes da Oceano Surfwear (fila 10 `WebChat OCEANO`, instância `oceano.evotalks.com.br`).

- Ao abrir o chat, a URA 15 pergunta com botões qual assistente testar: **Nalu** (B2B, lojista e representante) ou **Loja online** (consumidor de oceano.com.br).
- Recarregar a página volta como o **mesmo cliente** (para testar memória e histórico).
- **Novo cliente** (botão no topo) começa do zero.

Só para teste: desligar no go-live.
